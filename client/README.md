# RT | My Portfolio

## Project Description

This project is a personal portfolio website created using React. It presents my professional background, education, projects, services, and contact information in a multi-page portfolio website.

The website includes the following pages:

- Home
- About
- Projects
- Education
- Services
- Contact

The Contact page includes a form for visitors to enter their first name, last name, contact number, email, and message.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- React Router
- Vite
